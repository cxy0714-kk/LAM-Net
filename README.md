# LAM-NET

## Local Axial Mamba Network for Multi-class Vertebral Segmentation in CT Images

**Authors:** Hao Zuo, Tianming Zhao, and Chao Che  
**Affiliation:** Dalian University, China

LAM-NET is a 2.5D framework for multi-class vertebral segmentation in CT images. It combines ordered inter-slice context modeling, Adaptive Attention Skip Fusion (AASF), and hierarchical auxiliary supervision.
